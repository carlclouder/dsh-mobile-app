# 铠甲鲸鱼图标资产说明

日期：2026-10-21。状态：资源、独立审核、双包构建及最终0.1.195包的核心设备验收通过。

## 设计

按用户明确要求，在 DeepSeek 鲸鱼主体上穿铠甲，而不是只换背景或去掉鲸鱼。保留回旋姿态、面部、胸鳍及尾鳍，用额甲、连续背甲、侧甲和尾柄护套建立区别。银蓝金属、深色接缝和少量青蓝光边配深蓝底，避免原先一小条灰色装饰在桌面尺寸下不可辨认。

彩色源图由内置 imagegen 编辑生成，采用真实透明背景。原图已保存为 [launcher-armored-whale.png](../../tools/launcher-armored-whale.png)，不依赖用户目录中的生成缓存。[图标预览](../icon-preview.png)为实际导出结果。

## 资源与重新生成

从项目根执行：

```powershell
node tools/make-icon.cjs
```

生成器优先复用 sharp 0.35.5；缺少该版本时通过 npm 安装到已被 Git 忽略的 `.toolchain/icon-tools`。需要带 npm 的 Node.js。生成器统一导出48、72、96、144、192像素传统图标、432像素自适应前景与主题图标，并更新512像素预览。

Android 8及以上使用系统自适应裁切；Android 13及以上提供主题图标资源。主体位于108单位画布中心66单位安全圆内，避免圆形裁切损伤尾鳍。主题图标将明暗转换为透明度，以保留甲片分区。

通知使用的原终端向量继续独立保留，彩色启动图标不替代通知栏的单色小图形。应用名称与包名保持一致。

## 生成提示词

编辑现有App图标，设计一枚精致、辨识度高的“铠甲鲸鱼”前景角色，用于DSH Mobile安卓启动图标。必须保留参考图中DeepSeek白鲸的整体轮廓、卷曲侧身姿态、右侧头部、右上方尾鳍和友善眼神，但让鲸鱼真正穿上一套完整而连贯的未来感铠甲，和普通DeepSeek鲸鱼明显有区别。铠甲要有清楚的几何额甲、沿额头向左背部延伸的三块大背甲、侧身护甲及尾柄护套；白色鲸鱼面部、胸鳍与尾鳍仍露出。盔甲是蓝灰钛金属与浅银色，深色接缝、少量青蓝光边，主要由大块简洁面组成；不要只画一条灰色眉毛或狭窄背带。风格是高级移动App图标的干净矢量感插画，适量柔和立体明暗，边缘锐利，缩至48像素仍可识别，不要照片质感，不要密集铆钉、小纹理或复杂机械。单一角色完整居中，占画面约78%，四周留足透明边距；去掉原图蓝色方形底，输出真实透明背景，只有铠甲鲸鱼本体，不能有底板、投影地面、文字、字母、水印、其他角色或武器。
