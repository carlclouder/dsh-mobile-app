# 铠甲鲸鱼图标设备验收

日期：2026-10-21。最终安装版本：0.1.195（196）。

实际Android模拟器已覆盖安装最终Debug包，保留原设置。桌面底部右侧的`dev.dshmobile`显示深蓝底铠甲鲸鱼，圆形裁切保留头部、背甲、侧甲和尾鳍。

[continuous.gif](continuous.gif)连续记录启动器上的实际图标及点按启动后的App设置页；固定1500ms采样，16帧，动作前后均保留多帧。源图为`adb exec-out screencap -p`，仅等比例缩为540×1200再编码，无拼接、补帧或删帧。[capture.json](capture.json)保存原图校验值和采样时间，[frame-0002.png](frame-0002.png)为原始启动器截图。

图标源码、透明源图、重生成命令与完整生成提示词见[资产说明](../../docs/requirements/2026-10-21-铠甲鲸鱼图标.md)。五种传统尺寸、透明度、安全圆、资源引用和通知原图隔离已独立核对；最终双变体签名与安装包校验值见[构建验证](../message-order-20261021/verification.json)。

实际设备只验收当前模拟器的彩色自适应圆形图标和启动。其他启动器、传统图标回退路径及Android 13主题着色效果未做设备验收，不将资源检查当作这些环境的实际通过。
