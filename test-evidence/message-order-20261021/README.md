# 消息顺序与结束状态验收

日期：2026-10-21。基线：173c583。最终版本：0.1.195（196）。本会话已明确免审批。

## 实际场景与结果

在本地Android模拟器安装最终Debug包，经3081测试入口访问真实DSH，使用新建的独立验收会话。从App输入框连续发送两条完全相同的文字；没有从接口代替App发送，没有修改原有会话或全局模型。模型沿用deepseek-official/deepseek-flash和max思考级别。

发送前将模拟器墙钟调快300秒，直接覆盖原来“服务端时间不得早于手机”的匹配失败条件。宿主时钟未改。两轮完成后离开对话再重新进入；结束时已恢复模拟器原自动时间设置，实际偏差绝对值不超过2秒。

## 构建、回归与审查

全部功能编码完成并与设计校对后才补写和执行测试。`testDebugUnitTest`共192项，失败、错误、跳过均为0；`assembleDebug assembleRelease`成功，两种APK均通过签名校验。实际设备安装的是Debug包；Release完成构建与正式签名校验，未在本轮设备运行。

新增17项回归覆盖请求编号解析、真实HTTP请求编号、时钟偏差、缺时间、长排队、正文变化、重复同文、同键元数据补全、历史及实时去副本，以及真实状态机→状态流的结束发布。旧宿主保守匹配、拒绝状态、历史请求串行和正文优先规则的原有回归保持通过。

[verification.json](verification.json)包含测试计数、最终APK大小和SHA256、签名结果、设备版本及逐场景断言。[独立复核](REVIEW.md)记录源码与设备证据的可证范围。

首轮验收曾出现最终回复后仍显示运行状态，不能作为完整通过。已查明并修复状态机快照共享可变对象、状态流漏发布的问题，随后用最终包重验。含其他会话标题的原始完整录制保留在项目既有私有截图目录，公开证据改用返回到设置页的完整录制；没有通过剪帧隐藏异常。

## 验证边界

长时间排队、正文归一化及缺时间由实际Kotlin目标函数回归覆盖，未另做长时间设备录制。旧宿主不返回请求编号时仍保留原时间与文字匹配限制；本次没有旧宿主或真机、公网、不同启动器的验收结论。运行状态继续由宿主对账确认，不以某条助手回复或单次生成结束代替整个回合结束。
