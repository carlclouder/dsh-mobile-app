Android 本地模拟器安装本次 Debug 包，通过 adb reverse 连接本机真实 dsh 0.2.0-rc.2。使用独立会话“实时思考验收-1021”，不操作用户原会话的队列或交互。

录制尺寸540×1200，密度210。源图来自 `adb exec-out screencap` 原始像素，逐帧无损转为 PNG，再按序转为 GIF；没有绘制、补帧、插值、拼接或删去中间帧。

preview、controls各180帧，固定500ms；实际采样间隔分别为498–502ms、499–501ms。toggle为120帧、固定500ms，实际499–501ms。settled为16帧、固定800ms，实际799–801ms。每段均连续记录，不裁去等待或稳定画面。切换前后至少保留两帧的稳定状态；controls收起与上滑之间仅有一帧可见单行，因此该收起操作的稳定证据由toggle补足。

`*-capture.json` 保存逐帧原始像素及 PNG 校验值、采集时间和 GIF 校验值。完整 GIF 保留所有采样帧，另保留关键原始 PNG 便于定位；其余 PNG 属转换中间文件。
